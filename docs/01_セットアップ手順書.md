# FlowPilot セットアップ手順書（初心者向け）

所要時間：約30分　／　必要なもの：Googleアカウント、OpenAI APIのアカウント（クレジット残高あり）

> **大事な約束**
> - APIキーは **誰にも見せない・チャットに貼らない・ファイルに書かない**。この手順書で指定した場所（スクリプトプロパティ）にだけ入力します。
> - 入力するデータは **すべて架空** のものにしてください。
> - 画面の文言は Google や OpenAI の更新で少し変わることがあります。見つからないときは似た名前のボタンを探してください。

---

## 手順1　OpenAI の APIキーを作る

1. ブラウザで **https://platform.openai.com/api-keys** を開き、ログインします。
2. 右上の **「Create new secret key」** を押します。
3. Name に `FlowPilot` と入力し、**「Create secret key」** を押します。
4. 表示されたキー（`sk-` で始まる長い文字列）の横の **コピー** ボタンを押します。
   - このキーは二度と表示されません。手順5で使うまで、**メモ帳などに一時的に貼っておき、手順5が終わったら削除** してください。
5. （推奨）使いすぎ防止：左メニューの **Settings → Limits**（または Billing → Usage limits）で、月の上限額を低め（例：5ドル）に設定します。
   - 目安：問い合わせ1件あたり約1円未満です（テスト32件で数十円程度）。

## 手順2　スプレッドシートを作る

1. ブラウザで **https://sheets.new** を開きます（新しいスプレッドシートが作られます）。
2. 左上の「無題のスプレッドシート」をクリックし、`FlowPilot 管理台帳（デモ）` と入力して Enter。

## 手順3　Apps Script にコードを貼り付ける

1. スプレッドシートの上部メニュー **「拡張機能」→「Apps Script」** を押します。新しいタブでエディタが開きます。
2. 左上の「無題のプロジェクト」をクリックし、`FlowPilot` と入力して **「名前を変更」**。

### 3-1　設定ファイル（appsscript.json）を貼り付ける

1. 左端の **歯車アイコン（プロジェクトの設定）** を押します。
2. **「『appsscript.json』マニフェスト ファイルをエディタで表示する」** にチェックを入れます。
3. 左端の **`< >` アイコン（エディタ）** に戻ると、ファイル一覧に `appsscript.json` が表示されます。クリックして開きます。
4. 中身をすべて選択（`Ctrl + A`）して削除し、PCの次のファイルの中身をすべて貼り付けます。
   `FlowPilot\dist\appsscript.json`
   （ファイルを右クリック →「プログラムから開く」→「メモ帳」で開き、`Ctrl + A` → `Ctrl + C` でコピー）
5. `Ctrl + S` で保存します。

### 3-2　コード（FlowPilot.gs）を貼り付ける

1. ファイル一覧の **`コード.gs`** をクリックして開きます。
2. 中身（`function myFunction() {...}`）をすべて選択して削除します。
3. PCの次のファイルをメモ帳で開き、中身をすべてコピーして貼り付けます。
   `FlowPilot\dist\FlowPilot.gs`
4. `Ctrl + S` で保存します。エラーの赤い表示が出なければOKです。

### 3-3　Gmail と Tasks のサービスが追加されたか確認する

1. エディタ左側の **「サービス」** の欄に **`Gmail`** と **`Tasks`** が表示されていればOKです。
2. 表示されていない場合：「サービス」の横の **＋** を押し、一覧から **Gmail API** を選んで **「追加」**。同じように **Google Tasks API** も追加します（ID はそれぞれ `Gmail`、`Tasks` のまま）。

## 手順4　（ここは不要）Google Cloud でのAPI有効化について

Apps Script の「サービス」で追加した Gmail・Tasks は、Google が自動で有効にします。Google Cloud Console での操作は不要です。

## 手順5　APIキーを安全な場所（スクリプトプロパティ）に保存する

1. 左端の **歯車アイコン（プロジェクトの設定）** を押します。
2. 一番下までスクロールし、**「スクリプト プロパティ」→「スクリプト プロパティを追加」** を押します。
3. 次のように入力します。
   - プロパティ：`OPENAI_API_KEY`（すべて半角大文字）
   - 値：手順1でコピーした APIキー
4. **「スクリプト プロパティを保存」** を押します。
5. 手順1でメモ帳に貼ったAPIキーを削除し、メモ帳は保存せずに閉じます。

## 手順6　初期セットアップを実行し、権限を承認する

1. **スプレッドシートのタブに戻り、ページを再読み込み（F5）** します。
2. 数秒待つと、上部メニューの「ヘルプ」の右に **「FlowPilot」** が表示されます。
3. **「FlowPilot」→「初期セットアップ」** を押します。
4. 「承認が必要です」と表示されたら、次の順に進みます。
   1. **「OK」**（または「続行」）を押す
   2. 自分の Google アカウントを選ぶ
   3. **「このアプリは Google で確認されていません」** と出たら、左下の **「詳細」** → **「FlowPilot（安全ではないページ）に移動」** を押す
      - これは「自分で作ったスクリプトで、Googleの審査を受けていない」という意味です。自分のコードなので問題ありません。
   4. 権限の一覧が出たら、**「すべて選択」** にチェックを入れて **「続行」**
5. 承認後、もう一度 **「FlowPilot」→「初期セットアップ」** を押します（1回目は承認だけで終わることがあります）。
6. 「初期セットアップが完了しました」と表示され、**回答用フォームURL** が表示されます。このURLをメモしてください（後で「設定」と同じく確認できます）。
7. 下部のシートタブに **案件管理・ダッシュボード・処理ログ・設定** が増えていればOKです。（元からある「シート1」は削除して構いません）

### 承認される権限とその理由

| 画面の表示（例） | 理由 |
|---|---|
| このアプリケーションが表示されているスプレッドシートの表示と管理 | 案件管理台帳への書き込み（**このファイルだけ**） |
| Google フォームの表示、編集、作成、削除 | 問い合わせフォームの作成と回答の読み取り |
| メールの下書きの管理とメールの送信 | 下書き作成のため。※Googleの権限区分上「送信」も含まれますが、**コードに送信処理はありません** |
| タスクの作成、編集、整理、削除 | Google Tasks へのタスク登録 |
| 外部サービスへの接続 | OpenAI API の呼び出し |
| ユーザーがいないときにこのアプリケーションを実行できるようにする | フォーム送信時に自動実行するため |

## 手順7　OpenAI に接続できるか確認する

1. **「FlowPilot」→「OpenAI接続テスト」** を押します。
2. 「接続に成功しました」と分類・要約が表示されればOKです。
   - 失敗した場合はメッセージを確認してください。
     - `APIキーが未設定` → 手順5をやり直す
     - `HTTP 401` → APIキーが間違っている
     - `HTTP 429` → OpenAI のクレジット残高不足、または利用上限
     - `HTTP 404` や `model` を含むエラー → 「設定」シートの「OpenAIモデル」を確認

## 手順8　フォームから1件問い合わせを送ってみる

1. 手順6で表示された **回答用フォームURL** を開きます。
2. 次の **架空のデータ** を入力して送信します。
   - 氏名：`テスト 花子`
   - 会社名：`株式会社テスト（架空）`
   - メールアドレス：`test@example.com`（※ example.com は実在しないテスト専用ドメインです）
   - 問い合わせ件名：`事務所のエアコン交換について`
   - 問い合わせ内容：`事務所のエアコン2台を交換したいので、見積もりをお願いします。`
3. 1分ほど待ち、次を確認します。
   - **スプレッドシートの「案件管理」**：1行追加され、AI処理状況が「完了」
   - **Google Tasks**：Gmail 画面右側の **Tasks アイコン**（または https://tasks.google.com ）で、リスト「FlowPilot 問い合わせ対応」にタスクがある
   - **Gmail の「下書き」**：件名 `Re: 事務所のエアコン交換について [FP-...]` の下書きがある
   - **Gmail の「送信済み」**：何も送信されていない

> ここまでできたら、Claude Code に「手順8まで完了」と伝えてください。結果（どこで何が表示されたか）を教えてもらえれば、次のフェーズ（テストデータ32件での検証）に進みます。
> エラーが出た場合は、**エラーメッセージの文章**（APIキーは含めない）と「処理ログ」シートの内容を伝えてください。

## 困ったとき

| 症状 | 対処 |
|---|---|
| メニュー「FlowPilot」が出ない | スプレッドシートを再読み込み（F5）して10秒待つ |
| 「シート『案件管理』がありません」 | 「初期セットアップ」を実行する |
| フォームを送っても案件管理に何も出ない | Apps Script エディタ左の **時計アイコン（トリガー）** に `onFormSubmitHandler` があるか確認。左の **≡（実行数）** でエラー内容を確認 |
| AI処理状況が「エラー」 | 「注意・エラー内容」を確認し、原因を直してから「エラー・未完了の案件をまとめて再処理」 |
| AI処理状況が「要確認」 | 「注意・エラー内容」の指示に従って確認し、「選択中の行の案件を再処理」 |
