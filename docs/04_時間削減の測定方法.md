# 作業時間の削減効果の測り方

「AIを使うと、どれくらい時間が減ったか」を、思い込みではなく **実際に測った数字** で示すための手順です。

## 考え方

```
1件あたりの削減時間 ＝ 手作業でかかる時間 − FlowPilot を使ったときの確認・対応時間
削減率             ＝ 1件あたりの削減時間 ÷ 手作業でかかる時間
```

- **手作業でかかる時間**：問い合わせを読む → 台帳に書く → タスクをメモする → 返信メールを一から書く、の合計時間です。
- **FlowPilot を使ったときの時間**：AI の結果を確認する → 下書きを直す → 送信する、の合計時間です。
- AI の処理時間（平均13.5秒）は、人が待たずにほかの仕事をしていられるので含めません。ただし報告書には、参考として別に書きます。

## 手順1　手作業の時間を測る（基準づくり）

1. テストデータから、種類の違う5件を選びます（例：No.1、7、12、18、30）。
2. スマートフォンのストップウォッチを用意します。
3. 1件ずつ、FlowPilot を **使わずに**、次の作業をすべて手でします。
   - フォームの回答を読む
   - 案件管理シートの空いている行に、分類・要約・優先度・必要な対応を書く
   - Google Tasks にタスクを1つ作る
   - Gmail で返信メールを一から書き、下書きに保存する（送信はしない）
4. 1件ごとに、かかった時間（分）を記録します。
5. 5件の平均を出して、「設定」シートの **「手作業の想定時間(分)」** に入力します。初期値の15は仮の数字です。

> 手順3で使う問い合わせとは別のものを使ってください。同じ問い合わせだと、2回目は内容を覚えている分、早くなってしまいます。

## 手順2　測った結果を記録する表

| No | 種類 | 手作業の時間（分） |
|---|---|---|
| 1 | 見積依頼 | |
| 7 | 日程調整 | |
| 12 | サービス相談（緊急） | |
| 18 | その他 | |
| 30 | 複数の用件 | |
| **平均** | | |

## 手順3　FlowPilot を使ったときの時間を測る

1. 手順1とは **別の** 5件以上を選びます（例：No.3、8、15、20、33）。
2. 1件ずつ、次の作業の時間を測ります。
   - 案件管理シートで、AI の結果（分類・要約・優先度など）を確認する
   - Gmail の下書きを開き、必要なところを直す（本番ではここで送信する。テストでは送信しない）
   - 対応状況を「完了」にする
3. かかった時間（分）を、案件管理シートの **「確認・対応時間(分)」** 列（青い列）に入力します。

## 手順4　結果を見る

「ダッシュボード」シートの「■ 作業時間の削減効果」に、次の数字が自動で表示されます。

| 表示される項目 | 意味 |
|---|---|
| 手作業の想定時間（分/件） | 手順1で入力した平均 |
| FlowPilot利用時の平均確認時間（分/件） | 「確認・対応時間(分)」の平均 |
| 1件あたりの削減時間（分） | 上の2つの差 |
| 削減率 | 何％減ったか |
| 確認時間を入力した件数 | 測った件数 |
| 削減時間の合計（分） | 1件あたりの削減時間 × 件数 |

**月あたりの効果の見積もり**（報告書に書くとき）：

```
月の削減時間 ＝ 1件あたりの削減時間 × 月の問い合わせ件数
例）10分削減 × 月60件 ＝ 600分（10時間）
```

## 正直に報告するための注意

- 測るのは開発者本人なので、実際の会社の担当者より操作に慣れています。報告書には「開発者本人が測った」と書いてください。
- 件数が少ない（5件ずつ）ので、目安の数字です。
- 下書きの修正にかかる時間は、問い合わせの内容によって大きく変わります。平均だけでなく、最短と最長も書いておくと親切です。
- AI の利用料（1件あたり1円前後）も、あわせて書いておくと、費用対効果を判断しやすくなります。
